# RZ release metadata

Public release metadata only. No product source, ZIP archives, credentials or signing keys.

Planned layout inside this single directory:

- `registry.json`: generated signed registry used by embedded RZ runtimes.
- `<resource>.json`: complete published release history and changelog for one product.

No product release is published yet. These files must be generated by the private
release tooling, and activated only when the corresponding download is available.

Product history contract (not yet consumed by the SDK): schema_version=1,
product_id, releases. Each release has version, published_at and changes (list
of plain text lines). Versions are unique Semantic Versions. Entries represent
published releases only; drafts remain in private tooling.

For an installed version, show every published release with higher Semantic
Version precedence, ordered oldest to newest. Compare numeric version components,
not strings: 1.0.10 is newer than 1.0.9. Build metadata does not change precedence.
Development prereleases must not be advertised as stable releases.

The private release tooling must bind each history file to the signed registry
before it can become authoritative update information. The runtime integration
and publication automation are not implemented by this scaffold.
